Noah Guide Book

Basic information for operating and understanding Noah.

Noah is an AI-powered student-guidance robot. Its purpose is to help students learn, develop skills, explore interests and plan goals.
Noah can use a microphone for speech input, speech recognition to understand the user, an AI brain for responses and a speaker for voice output.
The current robot design uses a Raspberry Pi Zero 2 W as the main computer.
The Noah website is designed to become the public software-information and update hub. Automatic software updating will be added in a later version.
First restart Noah and check the software version. The troubleshooting and update system will be expanded as the project develops.

Support

Noah is an evolving project. This website will become the central place for documentation, software versions and future update information.
